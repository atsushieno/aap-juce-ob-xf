# aap-juce-ob-xf: port of OB-Xf to AAP

It is a port of [surge-synthesizer/OB-Xf](https://github.com/surge-synthesizer/OB-Xf), which is a fork of [reales/OB-Xd](https://github.com/reales/OB-Xd), to [Audio Plugins For Android (AAP)](https://github.com/atsushieno/aap-core), using [aap-juce](https://github.com/atsushieno/aap-juce).
